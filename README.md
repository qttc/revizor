# Ревизор

Мини-тула для правки текстов. Открываешь отчёт или дек и переписываешь как тебе нравится. Агент забирает правки и применяет их.

## Зачем

ИИ генерирует текст голосом нейросети. Править его в чате долго: копируешь абзац, объясняешь, где он лежит, пишешь замену, и так по каждому месту.

В Ревизоре правишь прямо в документе. Пары «было → стало» копятся рядом с ним, из них потом собираются примеры для скилла стиля. Отсюда «стоп нейрослоп».

## Как работает

1. В Claude Code пишешь `/revizor путь/к/отчёту.html` или «открой в редакторе». Открывается Chrome: документ слева, панель справа.
2. Правишь:
   - выделил фразу → «Изменить» – пишешь свою версию, агент заменит ровно её;
   - выделил фразу → «Комментарий» – просьба к этому месту;
   - «Выбрать блок» – комментарий к слайду, графику, таблице или разделу;
   - «Общий комментарий» – про документ целиком.
3. Пишешь агенту «поправь». Он применяет правки и отчитывается, что сделал и что отклонил.
4. Обновляешь вкладку и правишь дальше.

Правки сохраняются сами в `отчёт.review.json` рядом с документом. Формат текста (отчёт, дек, Slack, спека, письмо) Ревизор определяет сам, поменять можно в шапке панели.

## Что открывает

- HTML-отчёты и деки, в том числе со слайдами во фреймах и самораспаковывающиеся экспорты.
- Markdown в двух видах: «Оформление» – как увидит читатель, «Текст» – исходник с разметкой. Правки общие для обоих.
- `.txt`.

## Установка

```
git clone https://github.com/qttc/revizor.git
revizor/install.sh
```

Нужны Python 3.9+, Chrome и Claude Code, остальное лежит в репо. `install.sh` подключает скилл `/revizor`.

## Обновление

Вышла новая версия – агент предложит обновиться при запуске `/revizor`. Вручную – написать агенту «обнови ревизор» или `python3 revizor.py update`.

Документ и правки с компьютера не уходят. В сеть Ревизор ходит раз в сутки проверить версию, выключается `REVIZOR_NO_UPDATE_CHECK=1`.

Команды, формат файла правок и устройство – в [docs/technical.md](docs/technical.md).
