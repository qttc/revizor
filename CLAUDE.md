# revizor – правила для агента

Локальный редактор правок: сервер и CLI в `revizor.py`, слой правок в `web/overlay.js`, скилл в `skill/SKILL.md`. Устройство и формат – [docs/technical.md](docs/technical.md), README – для людей, без имён из кода.

## Инварианты

- Только stdlib Python 3.9+ и один JS-файл без сборки. Новая зависимость – только с одобрения владельца.
- Сервер слушает `127.0.0.1`, принимает только свой Host и свой Origin и раздаёт только папку документа без скрытых файлов. Файлы правок `*.review.json` закрыты даже внутри неё.
- Формат `*.review.json` читают внешние инструменты (у автора – сбор стилевых пар). Поле переименовать или убрать – поднять `version` и описать миграцию в CHANGELOG.
- DOM документа слой не меняет: подсветка через Highlight API, панель в shadow DOM.
- Необратимые действия в редакторе – только кликом с подтверждением, без горячих клавиш. Горячие клавиши не срабатывают при вводе в поле.
- Шрифты и Motion лежат в `web/vendor` с лицензиями. CDN и сеть в рантайме не нужны.

## Гейт

- `python3 -m unittest discover tests` зелёный.
- Правка `web/overlay.js` – проверка в Chrome на `tests/fixtures/markdown.md` в обоих видах, на тексте, на HTML-отчёте и на деке со слайдами во фреймах, на 1440 и 390 px: выделение, «Выбрать блок», ввод в поле при открытом тулбаре, перезагрузка с поиском места.
- Изменение поведения – раздел в `CHANGELOG.md` и та же версия в `revizor.py` (`__version__`), их совпадение проверяет тест. По тегу `vX.Y.Z` пользователи узнают о новой версии.
- Репо публичный: в коде, тестах, фикстурах и примерах только выдуманные данные. Никаких названий продуктов, компаний, метрик и текстов из рабочих документов.

## Коммиты

Conventional Commits, описание по-русски, `git add` с явными путями. Пуш и релиз – только по команде владельца.
