# revizor – правила для агента

Локальный редактор правок: сервер и CLI в `revizor.py`, слой правок в `web/overlay.js`, скилл в `skill/SKILL.md`. Устройство и формат – [README.md](README.md).

## Инварианты

- Только stdlib Python 3.9+ и один JS-файл без сборки. Новая зависимость – только с одобрения владельца.
- Сервер слушает `127.0.0.1` и раздаёт только папку документа. Файлы правок `*.review.json` закрыты даже внутри неё.
- Формат `*.review.json` читает `/graph-sync` в `personal-graph`. Поле переименовать или убрать – поднять `version` и описать миграцию в CHANGELOG.
- DOM документа слой не меняет: подсветка через Highlight API, панель в shadow DOM.
- Необратимые действия в редакторе – только кликом с подтверждением, без горячих клавиш.

## Гейт

- `python3 -m unittest discover tests` зелёный.
- Правка `web/overlay.js` – проверка в Chrome на тексте, на HTML-отчёте и на деке со слайдами во фреймах: выделение, «+ К блоку», перезагрузка с поиском места.
- Изменение поведения – строка в `CHANGELOG.md` и версия в `revizor.py` (`__version__`).

## Коммиты

Conventional Commits, описание по-русски, `git add` с явными путями. Пуш и релиз – только по команде владельца.
